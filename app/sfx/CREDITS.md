# Sound credits: Prayer Lock

Every sound is **CC0 1.0** (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/). No attribution is legally required; we credit the recordists anyway. Licences were checked on each source page on 18 Oct 2026.

Each file was trimmed, faded and loudness-normalised to about −22 to −24 LUFS ("soft") for the delight preview, then re-encoded for the app as mono Ogg Opus at 40 kbps (all ≤ 25 KB).

Sounds play only when Settings › Temple sounds is on **and** `PL.soundOk()` is true (ringer normal, Do Not Disturb off, media volume above zero). Never per bead, never in the desk japa, and not after 21:30 unless the user started the aarti.
